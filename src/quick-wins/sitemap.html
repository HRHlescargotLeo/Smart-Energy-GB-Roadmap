The sitemap index lists 164 pages but not Switch Up, Stay Smart. robots.txt blocks every URL with a query string, which includes all resized image URLs.

Generate the sitemap from Umbraco so new pages are included automatically, and let search engines crawl image URLs.

Why it's worth doing

Pages that aren't in the sitemap take longer to be found by search engines, which matters most for new campaigns.
